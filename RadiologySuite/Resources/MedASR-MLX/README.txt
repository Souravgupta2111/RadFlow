MedASR MLX FP16
===============

Drop `weights.npz` from https://huggingface.co/ainergiz/medasr-mlx-fp16
into this folder, or run:

  bash scripts/download_medasr_mlx.sh

If the file is missing, the app downloads it on first launch (~201 MB).
config.json is already here so the Conformer can be constructed.
